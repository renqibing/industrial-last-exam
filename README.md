# 工业设计 Last Exam

把你的专业经验变成 AI 的行业考题。我们已在化工、PCB 和 3D 建模中积累大量真实难题，并与 Stanford、Berkeley 等高校及国内多家知名企业合作，正在打造工业设计 Last Exam，让 AI 用专业软件完成真实工作。题目只看三点：真实、够难、能验收；难度要求是 GPT-6 Ultra 按验收标准得分低于 1%。你不必懂 AI，也不用自己测试，像交给同事一样交代任务就行。参与后，你能看清 AI 在自己工作中的真实能力，有机会参与联合研究，让你的经验影响行业标准。

网页包含 PCB 示例、提交说明图，以及任务包导出。附件随任务包保存，网页不自动发送用户资料。

## GitHub Pages

将本目录上传至仓库的 main 分支，在 Settings → Pages 中选择 Deploy from a branch，分支选择 main，目录选择 / (root)。

index.html 已内嵌样式，说明图使用相对路径加载；不需要安装依赖或构建。
