# 工程设计 LastXM

我们是一支关注 AI 与工程落地的跨学科团队。我们已在化工、PCB 和三维工程建模中积累一批真实任务，并与 Stanford、Berkeley 等高校及国内企业开展合作，正在打造「工程设计 LastXM」：用中试阶段的真实设计研发难题，检验 AI 能否用专业软件完成工程工作。题目要真实、够难、能验收；你不用懂 AI，像交给同事一样说明任务即可。参与者有机会与工程师、AI 研究者和产业伙伴交流、探索联合研究；达到贡献标准可参与论文联合署名，优秀贡献有机会获得奖金。

网页包含中试控制板填写示例、提交说明图和在线提交表单。点击“提交任务”后，填写内容和附件会保存到本项目后端；也可导出任务包留作备份。

页面右上角可在中文和 English 之间切换。背景、领域图、说明图、FAQ、表单、示例和提交提示均提供两种语言；切换会保留已填内容、附件和提交编号，并在浏览器中记住语言选择。也可通过 `?lang=zh` 或 `?lang=en` 直接打开指定版本。

## 收录阶段与规模

只征集中试及同等工程验证阶段的设计研发任务；实验室原理验证、生产执行和日常运维不在本轮范围内。

我们按应用阶段与工程要求划定范围，而不是仅按学科标签分类。科学研究成果可以作为起点，但任务必须落到中试应用、真实工程约束和可验收的设计交付。可以在专业软件里完成设计、建模、仿真或校核，不要求 AI 直接操作现场设备。

现有五项填写信息已够用：任务描述中说明中试应用、验证阶段、目标规模和主要约束；验收说明中提供检查办法及真实完成的参考结果。

## 计划征集的工程设计领域

从化工、PCB 和三维工程建模的积累出发，计划征集八个方向面向中试的设计研发任务：土木与建筑、机械与产品、化工与流程、集成电路、电路与 PCB、电气与控制、制造与工装、光学与光电。

网页通过一张窄幅 AI 绘制的领域图展示范围，手机可左右滑动查看。CAD 建模、仿真、优化与验证贯穿各领域，跨专业任务也欢迎。

## 难度与论文署名

本项目按同一验收标准测试 GPT-6 Astra 和 Claude Opus 5.5，取两者平均分（满分 1），你不用自己测试。
Near-term（近期挑战）：平均分低于 0.5（50%）；至少 3 道通过审核的题，达到论文署名门槛。
Last-exam（更难一档）：平均分低于 0.1（10%）；至少 1 道通过审核的题，达到论文署名门槛。
达到任一门槛，即具备论文联合署名资格（Data Contributor）。同一题的额外变体按 1/3 道计；参考结果须由实际运行产生，并提供清楚的验收标准。
发布前，我们会用届时最新强模型复测、筛题，确保题库在发布时仍有挑战性。
