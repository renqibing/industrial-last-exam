# 工业设计 Last Exam

把你的专业经验变成 AI 的行业考题。我们已在化工、PCB 和 3D 建模中积累大量真实难题，并与 Stanford、Berkeley 等高校及国内多家知名企业合作，正在打造工业设计 Last Exam，让 AI 用专业软件完成真实工作。题目只看三点：真实、够难、能验收。你不必懂 AI，也不用自己测试，像交给同事一样交代任务就行。参与后，你能看清 AI 在自己工作中的真实能力，也有机会参与联合研究、获得论文署名和奖金，让你的专业经验影响行业标准。

网页包含 PCB 示例、提交说明图，以及任务包导出。附件随任务包保存，网页不自动发送用户资料。

## 难度与论文署名

由我们按同一验收标准测试 GPT-6 Astra 和 Claude Opus 5.5，取两者平均分（满分 1），你不用自己测试。
Near-term（近期挑战）：平均分低于 0.5（50%）；至少 3 道通过审核的题，达到论文署名门槛。
Last-exam（更难一档）：平均分低于 0.1（10%）；至少 1 道通过审核的题，达到论文署名门槛。
达到任一门槛，即具备论文联合署名资格（Data Contributor）。同一题的额外变体按 1/3 道计；参考结果须由实际运行产生，并提供清楚的验收标准。
发布前，我们会用届时最新强模型复测、筛题，确保题库在发布时仍有挑战性。
署名规则参考并对齐：https://agents-last-exam.org/faq
